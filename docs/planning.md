# 토리 — 기획안

> 친구들과 여행하며 쓴 돈을, 여행이 끝나면 원화로 깔끔하게 나눠주는 정산 앱

## 1. 배경

친구들과 여행을 다니면 마지막에 각자 쓴 돈을 계산하는 게 늘 번거롭다. Tricount를 써보니 훨씬 편했지만, 해외 앱이라 한국 사람들끼리 쓰기엔 아쉬운 점이 있다.

- 정산 결과를 **원화**로 보고 싶다 (해외에서 쓴 돈도)
- 송금은 **토스·카카오페이**로 한다
- 초대는 **카카오톡**으로 보낸다

토리는 이런 한국 사람들의 여행 정산 습관에 맞춘 앱이다.

**목표 범위**

- 친구들끼리 실제로 쓰는 앱 (앱스토어 출시는 목표 아님, 무료 서비스 범위에서 운영)
- 친구들이 **각자 폰에서 같은 여행방에 들어와 함께 입력**
- 첫 사용처는 **중국 여행**: 위안화로 입력하고 원화로 정산
- 웹으로 먼저 만들고, 나중에 iOS/Android 앱으로 확장

## 2. 앱 이름과 콘셉트

**토리**: 도토리처럼 작고 둥근 이미지. "각자 모아둔 도토리를 공평하게 나눈다"는 뜻을 담았다.

- 마스코트는 도토리 캐릭터. 빈 화면, 정산 완료 축하 화면처럼 **포인트로만** 등장한다
- 전체 UI는 절제된 미니멀로 만들어 가볍거나 저렴해 보이지 않게 한다

## 3. 핵심 가치

| 가치                  | 내용                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------- |
| 3초 입력              | 금액만 치면 나머지는 기본값(낸 사람=나, 나눌 사람=전원, 통화=현지 통화)으로 바로 저장 |
| 외화 입력 → 원화 정산 | 여행 중엔 현지 통화로 기록하고, 정산할 때 원화로 "누가 누구에게 얼마"                 |
| 송금 편의             | 정산 결과에서 계좌번호 복사, 토스·카카오페이 열기                                     |
| 카톡 초대             | 초대 링크를 공유 시트로 카톡에 바로 보내기                                            |
| 유연한 나누기         | "술값은 안 마신 사람 빼고"처럼 일부 인원만 참여한 지출                                |

## 4. 기능 범위

### MVP

1. **여행방 만들기**: 이름, 기간, 멤버, 현지 통화, 정산 통화(원화 고정)
   - 현지 통화는 원화 / 엔화 / 위안화 / 달러 중 선택
   - 원화를 고르면(국내 여행) 환율 단계 없이 바로 정산
2. **초대와 입장**: 초대 링크 또는 8자리 코드로 입장 → "나는 누구?"에서 멤버 선택. 회원가입 없음
3. **지출 추가·수정·삭제**: 금액, 통화, 내용, 낸 사람, 나눌 사람(전원/일부), 카테고리, 날짜
   - 통화는 현지 통화가 기본이고 원화도 고를 수 있음 (한국에서 미리 결제한 항공권·숙소용)
4. **실시간 동기화**: 친구가 입력한 지출이 내 화면에 바로 반영
5. **잔액 보기** (여행 중): 현지 통화 기준 잔액 + "오늘 환율로 약 ○○원" 참고 표시
6. **정산하기**: 그날 환율을 불러와 확인 → 확정하면 환율 고정 → 원화 송금 목록 + 송금 완료 체크

### v2

- 환율 직접 입력 (실제로 환전한 환율로 바꾸기)
- 영수증 사진 첨부
- 금액 직접 분배 / 비율 분배
- 카테고리별 통계
- 계좌번호 등록 + 송금 앱 연결
- iOS/Android 앱 빌드, 푸시 알림
- 지원 통화 추가
- "나는 누구?"에서 이미 들어온 이름은 고르지 못하게 막기 (MVP는 고를 수 있고 주의 문구만 보여줌. 브라우저를 바꾼 본인이 다시 들어올 수 있게)
- 잘못 고른 이름은 방장이 멤버와 기기 연결을 직접 풀어 주기 (방장 권한, 연결 해제 RPC, 여행 설정 화면 필요)

## 5. 통화·환율·반올림 규칙

### 지원 통화 (1차)

| 통화          | 표기         | 최소 단위 | 저장 예시            |
| ------------- | ------------ | --------- | -------------------- |
| 🇰🇷 원화 KRW   | `12,350원`   | 1원       | 12,000원 → `12000`   |
| 🇯🇵 엔화 JPY   | `1,500엔`    | 1엔       | 1,500엔 → `1500`     |
| 🇨🇳 위안화 CNY | `128.50위안` | 0.01위안  | 100.50위안 → `10050` |
| 🇺🇸 달러 USD   | `$12.99`     | 0.01달러  | $12.99 → `1299`      |

- 엔화와 위안화는 둘 다 `¥` 기호를 써서 헷갈리므로 **한글 단위**(엔, 위안)로 표기한다
- 돈은 모두 **해당 통화의 최소 단위 정수**로 저장한다 (소수 계산 오차 방지)

### 환율

- 여행 중에는 환율을 정하지 않는다. 모든 지출은 **입력한 통화 그대로** 저장한다
- **정산하는 날의 환율 하나**를 모든 지출에 똑같이 적용한다
- "정산하기"를 누르면 그날 환율을 자동으로 불러와 보여준다
  - 예: `1위안 = 192.35원 (2026-10-25 기준)` → [이 환율로 정산]
  - 엔화는 `100엔 = 912.40원`처럼 100엔 단위로 보여준다 (한국에서 익숙한 표기)
  - 주말·공휴일에는 직전 영업일 환율이 나온다는 안내를 함께 보여준다
- 확정한 환율과 기준일은 여행방에 저장되어 친구들 모두 같은 숫자를 본다
- 확정 후 지출을 수정하면 "정산 다시 하기"로 다시 계산한다

### 나누기와 반올림

1. **지출 나누기는 입력한 통화의 최소 단위로 정확하게** 한다. 나누어떨어지지 않고 남는 값은 앞사람부터 1단위씩 더 낸다 → 합계가 항상 원래 금액과 같다

   | 지출           | 나누기 결과               |
   | -------------- | ------------------------- |
   | 100위안 ÷ 3명  | 33.34 / 33.33 / 33.33위안 |
   | $10 ÷ 3명      | $3.34 / $3.33 / $3.33     |
   | 1,000엔 ÷ 3명  | 334 / 333 / 333엔         |
   | 30,000원 ÷ 4명 | 7,500원씩                 |

2. 정산할 때 현지 통화 잔액에 환율을 곱해 원화로 바꾼다. **이 단계에선 반올림하지 않는다**
3. **송금 금액만 마지막에 10원 단위로 반올림**한다 (예: 12,346원 → 12,350원)
4. 반올림 때문에 생기는 차이는 송금 1건당 최대 5원. 정산 화면 아래에 "10원 단위로 반올림했어요"라고 안내한다
5. 송금 카드에는 원화를 크게, 현지 통화 환산액을 작게 표시한다: `지훈 → 수아 568,010원 (≈ 2,953.03위안)`

## 6. 화면 구성

### 화면 흐름

```
[첫 실행] 닉네임 입력
   ↓
[홈] 내 여행 목록 ──(+)──▶ [여행 만들기] ──▶ [초대하기]
   │                                         (링크 복사 / 카톡 공유)
   ▼
[여행 상세]  탭: ① 지출 내역  ② 잔액  ③ 정산
   │  (+ 버튼)                          │
   ▼                                    ▼
[지출 추가] ──▶ [지출 상세/수정]      [환율 확인] ──▶ [정산 결과(원화)]

[초대 링크로 들어옴] ──▶ [나는 누구? 멤버 선택] ──▶ [여행 상세]
[여행 설정] 이름·기간·멤버·현지 통화 수정, 여행 나가기
```

### 화면별 설계

| 화면        | 핵심 요소                                                                | UX 포인트                                          |
| ----------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
| 첫 실행     | 닉네임 입력 1칸                                                          | 회원가입 없이 바로 시작                            |
| 홈          | 여행 카드(이름, 국기, 기간, 총지출, 내 잔액)                             | 진행 중인 여행이 맨 위                             |
| 여행 만들기 | 이름 → 기간 → 통화 → 멤버                                                | 한 화면에 한 질문씩, 단계형                        |
| 초대하기    | 링크, 8자리 코드, 카톡 공유 버튼                                         | 여행을 만든 직후 자동으로 보여줌                   |
| 나는 누구?  | 멤버 이름 목록                                                           | 미리 만든 멤버와 실제 사람을 연결                  |
| 지출 내역   | 날짜별 목록(카테고리 아이콘, 내용, 낸 사람, 금액), 상단에 총지출·내 지출 | 오른쪽 아래 큰 + 버튼                              |
| 지출 추가   | 큰 금액 입력 + 통화 토글, 내용, 낸 사람, 나눌 사람, 카테고리             | 기본값만으로 저장 가능, 1인당 금액 실시간 미리보기 |
| 잔액        | 멤버별 막대(받을 돈 파랑 / 줄 돈 빨강), 현지 통화 + "약 ○○원"            | 내 행 강조                                         |
| 환율 확인   | 오늘 환율, 기준일, 원화 환산 총액                                        | 확정 전 한 번 더 확인                              |
| 정산 결과   | "누가 → 누구 · 원화(현지 통화)" 카드, 계좌 복사, 완료 체크               | 완료한 항목은 흐리게, 전부 끝나면 토리 축하 화면   |
| 여행 설정   | 이름·기간·멤버·통화 수정                                                 | 지출이 있는 멤버는 삭제를 막고 이유를 안내         |

### 빈 화면과 오류 상태

- 지출이 0건일 때: 토리 그림 + "첫 지출을 추가해보세요" 버튼
- 인터넷이 끊겼을 때: 상단에 연결 끊김 표시
- 환율을 불러오지 못했을 때: 다시 시도 버튼
- 삭제할 때: 한 번 더 확인

## 7. 디자인 방향

- **콘셉트**: 토스처럼 깔끔한 미니멀에 도토리의 따뜻함을 더한다. 숫자가 주인공
- **컬러**
  - 따뜻한 흰색(아이보리) 배경 + 도토리 브라운/캐러멜 포인트 컬러
  - 받을 돈 = 파랑, 줄 돈 = 빨강 (한국 금융 앱 관례)
  - 시안 2개 비교: A. 브라운 단독 / B. 브라운 + 잎사귀 그린
- **글꼴**: Pretendard
- **레이아웃**: 한 손 조작. 주요 버튼은 화면 아래쪽, 터치 영역은 크게
- **컴포넌트**: Material 3 기반에 토리 테마를 입힌다. 다크 모드 지원
- **카테고리**: 🏨 숙소 · 🍜 식비 · 🚕 교통 · ☕ 카페 · 🍺 술 · 🎡 놀거리 · 🛍 쇼핑 · 📦 기타
